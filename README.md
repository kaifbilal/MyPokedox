# MyPokedex

MyPokedex is a simple web application that allows users to search for Pokémon by name or number and view their details. It uses the [PokéAPI](https://pokeapi.co/) to fetch real-time Pokémon data.

## Features

- Search for Pokémon by name or number
- View Pokémon details such as image, type, and stats
- Responsive and clean UI

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, etc.)

### Running Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.

No build steps or server required.

## Project Structure
MyPokedex/ ├── index.html ├── styles.css ├── pokedex.js └── README.md

## Customization

- Update `styles.css` to change the look and feel.
- Modify `pokedex.js` to add more features or enhance functionality.
